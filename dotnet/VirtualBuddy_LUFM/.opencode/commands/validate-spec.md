---
description: Validar que una spec esté lista para implementarse
---

Valida la siguiente spec utilizando el proceso SDD:

$ARGUMENTS

Comprobar:

- objetivo claro;
- scope;
- requisitos funcionales;
- reglas de negocio;
- inputs;
- outputs;
- validaciones;
- errores;
- edge cases;
- dependencias;
- affected flows;
- acceptance criteria;
- tests;
- preguntas abiertas;
- contradicciones.

Clasificar hallazgos como:

- BLOCKER
- IMPORTANT
- OPTIONAL

No implementar código.

Solo establecer status READY cuando no existan
BLOCKERS ni decisiones funcionales pendientes.
