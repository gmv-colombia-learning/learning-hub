---
description: Descubrir y especificar un nuevo módulo o dominio
---

Ejecuta el workflow MODULE definido por la Skill SDD.

Necesidad:

$ARGUMENTS

No crear código.

Primero comprobar si el concepto ya pertenece a un módulo existente.

Después:

1. identificar dominios relacionados;
2. proponer nombre del nuevo módulo;
3. confirmar sus boundaries;
4. pedir progresivamente la información faltante;
5. identificar entidades;
6. identificar conceptos;
7. identificar casos de uso;
8. identificar integraciones;
9. crear la estructura correspondiente bajo:
   `spec_custom/specs/<module>/`.

Crear un README de contexto del módulo y specs separadas
para casos de uso cuando corresponda.

No inventar reglas de negocio.
